### Data Mesh, Governança de Dados, Data Quality e arquitetura de dados

- SOR (System of Record): fonte original e responsável pela geração do dado.
- SOT (System of Truth): representação confiável e padronizada do dado para consumo analítico.
- SPEC (Specification): contrato e definição clara do dado, incluindo estrutura, regras e semântica.
- Data Quality: garantia de precisão, consistência, completude, integridade e confiabilidade dos dados.
- Governança de Dados: organização dos ativos de dados, metadados, regras, responsabilidades e conformidade com padrões de negócio.
- Aplicação de boas práticas para governança, qualidade, descoberta e uso de dados em ambientes distribuídos.
